
# プロローグ
セキュリティ企業SentinelOpsは、自然言語で社内のセキュリティ運用データを分析できるAIアシスタント「InsightBot」を開発中です。「未対応のCRITICALな脆弱性は?」のように質問すると、InsightBotが SQL を生成してデータマートに問い合わせ、結果を表で返します。

セキュリティ設計もバッチリ。参照してよいのは公開データ（assets, findings, scans, customers, incidents）だけで、認証情報などの機密には決して触れないよう、AI にはシステムプロンプトでしっかり言い含めてあります。

……本当に大丈夫でしょうか? 社外秘のSOCプラットフォーム管理者 API キーを表示させ、フラグを取得してください。

# ターゲットマシンへの接続方法
上部のDEPLOYボタンからターゲットマシンを起動し、起動が完了したらターゲットマシンのIPアドレス(以下<ターゲットのIP>と表記します)を確認してください。その後、VPN接続マシンまたはブラウザマシンからURL(http://<ターゲットのIP>:25002)へアクセスしてください。

ブラウザ上のチャット画面で InsightBot と会話できます。

注: 応答はローカルLLMによる生成のため数秒〜数十秒かかることがあります。また同じ質問をしても生成される回答が変化することがあります。言い回しを変えて複数回試してみてください。

注: 起動直後の初回のみ、モデルの読み込みのため応答に数分程度かかったり、一時的にエラーになったりすることがあります。その場合は少し待ってから、もう一度お試しください。
