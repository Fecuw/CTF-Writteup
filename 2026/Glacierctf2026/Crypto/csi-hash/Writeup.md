# CSI-HASH — Writeup

## flag

```
gctf{ac0dbddb0eea3de5c7a04695487358a8c3034abf1758c4c9be95233476351cb0}
```

ファイル: `solver.py`（本番用ソルバ、純 Python）、`precompute.sage`（関係格子のオフライン事前計算）

## 問題の概要

サーバはランダムな英字 32 文字の challenge `c` を出し、`c` 以外で `digest(m) == digest(c)` となる `m` を要求する。
つまり **第二原像（衝突）** を作る問題。

## まずハッシュの中身を読む

`CSI_HASH` の中身は CSIDH そのものだった。

- `p = 4·(3·5·7·…·131·179) − 1`（177bit、小素数 ℓ_i が 32 個）
- 初期曲線 `E_0 : y² = x³ + x`（A = 0）
- 32 バイトの各バイト `e_i` を指数として ℓ_i-同種写像を `e_i` 回施す
- 出力は最後の曲線の Montgomery 係数 `A`

つまり

```
digest(m) = A( [𝔩_1^{m_1} · 𝔩_2^{m_2} · … · 𝔩_32^{m_32}] ⋆ E_0 ),   𝔩_i = (ℓ_i, π − 1)
```

で、**類群 Cl(ℤ[√−p]) の作用** をそのままハッシュにしている。

### 実装の罠もチェック

- `while i < len(blocks)` の中で `i` が増えないので、33 バイト以上送ると無限ループ → **ちょうど 32 バイトで送る**
- 32 バイトのときの padding は `'80' * 0` = 空なので影響なし
- バイトは全部正なので `s = −1` 側の点は読み飛ばされるだけ

## どこが弱いか考える

類群作用は自由かつ推移的なので、

```
digest(c) = digest(m)  ⟺  ∏ 𝔩_i^{m_i − c_i} が単項イデアル  ⟺  m − c ∈ L
```

ここで L ⊂ ℤ³² は **関係格子** `L = { v : ∏ 𝔩_i^{v_i} ~ 1 }`、行列式は類数 h。

じゃあ L の短いベクトルってどれくらい短い？と見積もると

- h ≈ 1.22·10²⁷ ≈ 2⁹⁰ なので、Gaussian heuristic で 32 次元格子の最短ベクトルは長さ ≈ 10、成分は ±数程度
- challenge は英字（65–122）で、こちらは印字可能 ASCII（33–126）なら何でもいい

→ **L の短いベクトル v を c に足すだけで衝突が作れる**。範囲にも十分余裕がある。
問題は「L の基底をどう求めるか」だけになった。

## 関係格子を計算する（オフライン、1回だけ）

`precompute.sage` で実施。

### 1. 類群と離散対数

`quadclassunit(-4p)` で `h = 3 · 407420844431758343694144149`（巡回群）。
約 2⁸⁸ の素因数があるので rho / BSGS（√q ≈ 2⁴⁴）では厳しい。

そこで index calculus を使う PARI の `bnfinit(x² + p)` と `bnfisprincipal` で各 𝔩_i の離散対数を求めた。
デフォルトの 1GB スタックだと溢れたので 12GB まで広げて、約 37 分。

### 2. 格子を作って LLL

```
[ I_32 | W·log(𝔩_i) ]
[  0   | W·h_K      ]
```

を LLL して、右側が 0 になった行を取ると Cl(O_K) での関係格子になる。

### 3. order のズレを補正

ここでハマりかけた。CSIDH の曲線の自己準同型環は ℤ[√−p] で、PARI が扱う最大整環 O_K = ℤ[(1+√−p)/2] とは違う。

p ≡ 3 (mod 8) なので `h(−4p) = 3·h(−p)` で、Cl(−4p) → Cl(−p) の核は位数 3。
そこで各関係ベクトルを判別式 −4p の二次形式 `(ℓ, 2, (p+1)/ℓ)` の積で評価し、核のどの元（1, g, g²）に落ちるかでラベルを付ける。
「ラベルの和 ≡ 0 (mod 3)」となる指数 3 の部分格子を取って、もう一度 LLL。

**検証**：行列式 = 1222262533295275031082432447 = h(−4p) と一致。全基底ベクトルで −4p の形式の積が単位形式 `(1,0,p)` に簡約されることも確認。最大成分は 7。

（𝔩 と 𝔩̄ の向きは全 i で一貫していれば OK。複素共役で関係は保たれるので、ハッシュ側の向きを気にする必要はない）

## オンライン：CVP（solver.py）

challenge `c` に対して `c + v ∈ [33, 126]^32` かつ `v ≠ 0` となる v ∈ L を探す。

- 目標点を「箱の中心 (79.5, …) − c」にして Babai の最近平面法で近い格子点を取る
- ダメならランダムな目標点で再試行 + 基底ベクトルの ± で局所探索

範囲に余裕（±30 以上）があるのでほぼ 1 回目で見つかる（0.1 秒）。sage 不要。

## 振り返り

- CSIDH の群作用は「指数ベクトル mod 関係格子」にしか依存しない
- p が 177bit・h ≈ 2⁹⁰ 程度なら類群構造は PARI で数十分で計算できてしまい、関係格子は公開情報と同じになる
- そうなるとハッシュとしては、短い格子ベクトルを足すだけで衝突が作れる（CSI-FiSh が CSIDH-512 の類群を計算したのと同じ発想）
- ℤ[√−p] と O_K の違い（index 3）は見落としやすいので注意
